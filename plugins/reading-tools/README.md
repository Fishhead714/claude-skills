# reading-tools

| Skill | What it does |
|---|---|
| [`reading-mentor`](skills/reading-mentor) | A reading mentor that decides what to read next from a domain map and checks whether it went in with a closed-book retelling after each book, keeping a domain map, verified reading list and append-only log in plain Markdown so every session resumes where the last one stopped. |

It is a prompt-only skill: it checks that a book exists (not whether it is good) and has no scheduling or reminders.
