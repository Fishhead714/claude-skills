# windows-desktop

| Skill | What it does |
|---|---|
| [`glazewm-desktop`](skills/glazewm-desktop) | One-script setup for a tiling Windows desktop: GlazeWM (tiling window manager) plus YASB (status bar) showing workspace numbers and a local CPU / memory / disk indicator, with a troubleshooting guide. |

Windows only; not for Linux or macOS. `assets/glazewm-config.yaml` and `assets/yasb-styles.css` are adapted from GlazeWM and YASB and remain under their original licenses; see the skill's [`THIRD_PARTY_NOTICES.md`](skills/glazewm-desktop/THIRD_PARTY_NOTICES.md).
